# General Information

Our aim is to improve the engine harness. Cheating or workarounds don't help us.

## Working rules
- We have power to do anything, be brave!
- For the rendering scripts use process.exit so that it doesn't hang.
- Find the root cause when debugging. If a workaround is the only option, stop and ask before proceeding.
- Aim for an elegant solution: think engineering elegance, not only goal completion.
- No `any`. Named exports unless a default is required. Top-of-file imports; no `await import` unless required.
- Code must pass the cyclomatic complexity lint.
- Use pnpm only. Never hand-edit `pnpm-lock.yaml`; use `pnpm add/remove/install`.
- Never run bare `tsc` (it emits `.d.ts`/`.js` into source). Use the package's own script (`tsdown`, or `tsc --noEmit -p .`).
- Do not run `pnpm dev`. Do not use a browser to test (needs Google auth); verify headlessly.
- No fancy colors in console/log output.
- Don't use the user's name in messages. Final answer: concise, no yapping.
- Keep this file current: when structure or dev patterns change, update it.

## Repo map

Gitframes is a code-first video engine on native WebGPU (Dawn) in Node, with no browser. pnpm + turbo monorepo, Node >=22, ESM, Biome (tabs, double quotes), tsdown builds, vitest tests. Rendering needs a GPU.

- `packages/gitframes`: the public SDK. `Composition`, `Layer.*`, `LayerAnimation`, `Signal`, effect classes (`src/effects/classes.ts`), `FontManager`, `renderFrameGrid` (`src/renderer/framegrid.ts`). `src/index.ts` is large and is the export surface.
- `packages/compositions`: layout (Yoga, `utils/layout/resolve-layout.ts`), program schema (`program/schema.ts`), animation and evaluator, `to-virtual-media`.
- `packages/webgpu-renderers`: WGSL shaders, 2D/3D pipelines, Slug text, audio DSP, ChartGPU bridge.
- `packages/renderer`: headless Node renderer (Dawn, WebCodecs/mediabunny, `HeadlessMediaRenderer`).
- `packages/core`: shared types, `Effect` base, signals. Other packages: `renderers`, `media`, `node-sdk` (node authoring: `shared/` + `renderer/`), `server-utils`, `client-utils`, `tensor-webgpu`, `vision`, `tsconfig`.
- `nodes/node-*` (59): one VFX/audio/layout node each. Layout: `src/shared/` (config and schema), `src/renderers/` (WebGPU), `src/index.ts`. Only `node-compositor` has a `SKILL.md`; update it when Compositor behavior changes (`packages/compositions/src/program/skillmd-check.test.ts` guards it).
- `apps/renderer-service`: HTTP render service (Docker, RunPod worker).
- `examples/NN_*`: reference films/ads that import `gitframes` via workspace. Study `19_gitframes_film` (best structure), `22_gitframes_launch` before writing a new film.
- `plugins/gitframes/skills/gitframes{,-compose,-effects,-render}`: agent skills, symlinked from `.agents/skills` and `.claude/skills`.
- `examples/22_gitframes_launch`: reference for a lyric-driven launch film.
- Package `exports` have a `development` condition pointing at `src/`. Otherwise consumers resolve `dist/`, so run `pnpm build` after changing a dependency.

## Commands

- Build: `pnpm build` (turbo, `^build` first). Single package: `pnpm --filter <name> build`.
- Test: `pnpm --filter <name> test` (vitest; `packages/renderer` uses `test:vitest`). Root `pnpm test` runs everything and is slow.
- Lint and format: `pnpm exec biome check --write <files>` (lefthook runs it on commit).
- Example: `pnpm --filter @gitframes/example-19-gitframes-film assets|render|test|typecheck`.
- Agent skills: after changing engine API behavior, update the owning skill or reference, then run `pnpm run check:plugins`. `plugins/gitframes/skills/gitframes-effects/references/effects-catalog.md` is generated by `pnpm run sync:effects-catalog`; never hand-edit it.
- Version bumps: use changesets (`.changeset/`).

## Ignored, local-only files

Fonts (`assets/fonts`), `*.mp4/mp3/wav/png/jpg`, `*.onnx`, `scratch*/`, `examples/output/`, `.hermes/` and `.env*` are gitignored. Never commit them or print secrets from `.env`. Write throwaway probes and logs under a `scratch/` or `output/` dir.

- Every font in `Layer.text` must be registered with `FontManager` and declared in `fonts`. There are no system fonts headlessly.

## Engine gotchas (violations fail silently)

- Premultiplied-alpha shaders use blend `srcFactor: "one"`, never `"src-alpha"` (it squares alpha and fades go murky grey).
- WGSL: every declared storage binding must be used, or Tint optimizes it out of the layout.
- Clamp scissor rects to non-negative integers within the surface.
- Signals are class instances; never `{ ...signal }` (it loses `.get(ctx)`). A `NaN` reaching a uniform turns the whole frame black with no error.
- `CompositorProgramSchema` is `.strict()`: a new field on a node or the program must be added to `program/schema.ts` (base nodes, media nodes, and the root for `effects`) or `comp.toSpec()` fails validation even though rendering works.
- Track keyframe frames and effect frame options must be integers (e.g. `Math.round(life * 0.55)` for a computed fade-out frame), or the schema rejects the program.
- The audio extractor scales hot multi-track sums; master soundtrack layers to roughly -14 dBFS RMS yourself and keep the summed peak near 0.9.
- Procedural SFX triggers render procedural whoosh/riser/impact/downshifter/glitch on the CPU (`renderSfx`, `mixSfxInto`, `softLimit`). `atBar` is where the effect *starts*: a whoosh peaks 0.42s in, so start it ~0.21 bars before the cut.
- `withAnimation` must keep `animation` an enumerable data property so `{ ...node }` spreads keep the tracks.
- Keep `isAbsolutePositioned` symmetric between `buildYogaNode` and `readLayout` in `resolve-layout.ts`, or coordinates double-add.
- Compositor specs: audio inputs go in `config.layout` as `kind: "media"` items with `inputHandleId` and `volume`, or the headless mixer drops them. Fonts go in the top-level `"fonts"` array with relative paths. Use the live handle ID, not its label, for `inputHandleId`.
- Path text (`pathOptions`) coordinates are local to the text node's box, like any child; rotation/scale pivot on the node's anchor. Size the node to contain the path.
- Shape paths support SVG arcs (`A`/`a`); a circle is two arcs (`M c c-r A r r 0 1 1 c c+r A r r 0 1 1 c c-r`) and draws on with `trimEnd`.
- A circular window: put the plate and a `Layer.shape("ellipse", { blendMode: "mask-in" })` in a box with `background: "transparent"` (any painted background makes the box its own layer group; without one the mask cuts everything beneath).
- Do not add per-effect helpers like `blurTrackedRegion`. Extend `comp.section` / `Layer.section` instead.

## Authoring API traps

- `LayerAnimation` has no `moveX`, `moveY`, `scale`, `rotate` or `trimPath`. Use `fromTo(prop, from, to, { start, end, ease })`.
- `fadeIn` and `fadeOut` take positional args: `.fadeIn(0, 20, "power2.out")`.
- Borders are `borderColor` plus `borderWidth`. CSS `border` is silently ignored.
- Setting only `x` or `y` makes a node absolute. Use `position: "relative"` to nudge a flow child. A centered flex needs an explicit `width` (or `"fill"`).
- Keyframes are relative to the node's own window. Never add the parent's `startFrame`. Animating `y` overrides layout `y`, so animate `fromTo("y", y + 40, y)`, not to `0`.
- Valid ease bases: `none power1 power2 power3 sine circ expo back elastic bounce spring cubic hold`. There is no `power4`.
- Don't nest an opaque-background container inside a `tilt3D`/`rotateX`/`perspective` container. Make one unified card.
- Every font in `Layer.text` must be registered with `FontManager` and declared in `fonts`. There are no system fonts headlessly.
- Every audio layer needs `durationFrames` (`audio.totalFrames`), or it cuts out early.

## Video taste

Follow `plugins/gitframes/skills/gitframes-compose/SKILL.md`. Build like a designer with an engineer's discipline.

- **Tokens first:** `theme.ts` with palette, type scale, spacing, radii, eases, and one `BEAT` constant.
- **Native layout trees only:** Never fake a UI, chart or screenshot with a pre-rendered bitmap.
- **One clock:** Captions or voiceover first, then the BeatGrid, then reading pace (~2.4 words/s). Generate audio first and derive timing from it. Never guess frames or slice the timeline evenly.
- **Restrained hierarchy:** One idea per shot, one focal point, generous negative space. Huge display size, small tracked-out label, high contrast.
- **Decisive motion:** Enter with deceleration (`expo.out`, `power3.out`, `back.out(1.5)`, spring). Exit fast (`power2/3.in`). Never use linear easing on position, scale, or rotation. Stagger siblings by 2-4 frames.
- **Verify before claiming done:** Use the ladder: typecheck -> schema parse -> `renderFrame` -> `renderFrameGrid` -> pixel probes -> `renderVideo` + `ffprobe`.
